## 🎯 About PDF Hawk

**PDF Hawk** is an all-in-one document workspace designed for speed, flexibility, and absolute privacy. Built with Flutter, it delivers a suite of document management tools without requiring cloud accounts, subscriptions, or external servers. All rendering, editing, conversion, and cryptographic operations occur 100% locally on your device.

---

## ✨ Key Features

- 📖 **High-Performance PDF Reader**
  - Instant page rendering with pinch-to-zoom and multi-level zoom controls
  - Vertical and horizontal reading modes
  - Thumbnail previews, page bookmarking, and quick jump navigation

- ✍️ **Rich Document Writer & Editor**
  - Full-featured rich text editing powered by Quill delta formatting
  - Convert DOCX templates directly into editable documents
  - Custom typography, headers, checklists, colors, and embedded media
  - Instant one-tap export to standardized PDF documents

- 🛠️ **Master PDF Page Operations**
  - **Split**: Extract specific page ranges or split PDFs into individual documents
  - **Merge**: Combine multiple PDF files into a single unified document with custom sequencing
  - **Rearrange & Reorder**: Interactive drag-and-drop page grid to reorder, rotate, duplicate, or delete pages

- 🔄 **Document & Image Converter**
  - Convert image collections (PNG, JPEG, WebP) directly into multi-page PDFs
  - Import and parse Microsoft Word (`.docx`) documents
  - Export PDF pages to crisp, high-resolution image files

- 📷 **Built-in Document Scanner**
  - Real-time hardware camera with level gauge and tilt stabilization indicators
  - Multi-page continuous capture mode
  - Image cropping, perspective optimization, and contrast enhancement

- 🖋️ **Digital Signatures & Annotations**
  - Smooth vector signature pad to sign documents on the go
  - Stamp and position saved signatures directly onto PDF pages

- 🎨 **Dynamic Themes & Custom Palettes**
  - Full support for both **Dark Mode** and **Light Mode**
  - Dynamic primary accent color picker with live app-wide theme updating
  - Material 3 design system

- 🔒 **Privacy by Design**
  - Zero telemetry, cloud uploads, or data harvesting
  - Works entirely offline

## 🚀 Getting Started

### Prerequisites

- [Flutter SDK](https://flutter.dev/docs/get-started/install) (3.12+ or latest stable)
- Android Studio / VS Code with Flutter and Dart extensions
- Android device or emulator (API level 21+)

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/vow-sta-n/pdf-hawk.git
   cd pdf-hawk
   ```

2. **Install dependencies**:
   ```bash
   flutter pub get
   ```

3. **Run the application**:
   ```bash
   flutter run
   ```

4. **Run unit tests**:
   ```bash
   flutter test
   ```
